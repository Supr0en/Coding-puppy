# Coding-puppy
Coding-puppy is the way i think AI is best used and how i want to use AI in my own project workflow.
---
### How to use
If you are on windows install wsl else you can continue.

1. Install Ollama and model you want to run/fits your device.
2. Clone this repository.
3. Run setup.py script.
4. Run coding-puppy.py, run this by using command <path-to-script>/coding-puppy.py (this can be run in projects directory).

#### Optional

If you want to run with allias add this in your .bashrc or .zshrc file in root.

```
alias coding-puppy='python3 /path/to/your/coding-puppy.py'
```
Replace python3 with which python you use (pip/pipx, python, etc).
